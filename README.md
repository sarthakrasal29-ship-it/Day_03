# Basic Calculator in C

A beginner-friendly C program that takes two integer numbers as input and performs basic arithmetic operations.

### Operations

* Addition
* Subtraction
* Multiplication
* Division

### Concepts Used

* `printf()` and `scanf()`
* Integer variables
* Arithmetic operators
* `fflush(stdout)`
* Basic input/output in C

### Example

Input:
`20 5`

Output:

* Addition: 25
* Subtraction: 15
* Multiplication: 100
* Division: 4

### Note

Division uses integer division, so decimal values are truncated.
